Тихий вечер — отдельные спрайты для Unity

Состав набора:
room_base.png — чистый фон комнаты со столом; котят, окна, лампы и чашки на нём нет.
window_rain.png — отдельное окно с дождливым городом.
kitten_ginger.png — рыжий котёнок, Персик.
kitten_cream.png — кремовый котёнок, Соня.
kitten_tabby.png — серый полосатый котёнок, Туман.
lamp_on.png — включённая лампа.
lamp_off.png — выключенная лампа.
tea_mug.png — чашка с чаем и подставкой.

Все предметы сохранены как PNG с настоящим альфа-каналом. Фон непрозрачный.
Для импорта подготовлены отдельные .meta: Sprite (2D and UI), Single, Pixels Per Unit 100, центральный Pivot.
Лампа в обоих состояниях имеет одинаковый холст 1024 x 1536; положения силуэтов проверены.
Объекты имеют разные размеры исходных изображений: масштаб и положение каждого настраиваются отдельно.

Как собрать в своей сцене:
1. Остановить Play и открыть Room_Podyganova_Karina.
2. В Project открыть Assets > LofiRoom > Art > QuietEveningLayers.
3. Назначить room_base в Room > Background > Sprite Renderer > Sprite.
   Для камеры Size 5 и формата Game 16:9 начальные настройки фона:
   Position (0, 0, 5), Rotation (0, 0, 0), Scale (1.064, 1.064, 1), Order in Layer -100.
4. Перетаскивать отдельные PNG из Project в Scene или Hierarchy, создавая отдельные объекты.
   Окно разместить на свободном левом участке стены; серого котёнка — рядом с подоконником;
   рыжего — у раскрытой тетради; кремового — на зелёном пледе;
   лампу — на столе рядом с книгами; чашку — на свободном участке стола.
5. Подогнать размеры и положение каждого предмета инструментами W и R, проверяя результат в Game.
   Рекомендуемые Order in Layer на одном Sorting Layer:
   фон -100, окно -80, котята 10, лампа 20, чашка 30.
6. Добавить Box Collider 2D и Room Interactable для кликабельных котят, чашки или окна.
   Подогнать каждый коллайдер под видимую часть своего спрайта, исключая большие прозрачные поля.
   В Room Interactable назначить Banner из UI Canvas > MessageBanner,
   Tracker из Systems > DiscoveryTracker и Sfx Source из Ambience > Src_UI_OneShots.
   Заполнить Title, Message и Extra Messages.
7. Для лампы использовать Toggleable Prop: назначить Target Renderer, On Sprite = lamp_on,
   Off Sprite = lamp_off, Banner и Tracker. On Message и Off Message описывают изменение света.
8. Сохранить сцену Ctrl+S и проверить нажатия в Play.

В этой композиции стол занимает передний план, а справа находятся полки и книги.
Для сохранения свободного места вокруг котят камин можно отключить в своей сцене.
Если камин требуется оставить, для него стоит отдельно спланировать свободный участок стены и пола.

Происхождение изображений: встроенный ImageGen; редактирование и выделение объектов из ранее созданной иллюстрации «Тихий вечер».
Промпты записаны в generation_prompts.json.
